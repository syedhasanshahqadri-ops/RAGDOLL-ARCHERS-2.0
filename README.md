RAGDOLL ARCHERS HD
Play: open index.html (works offline in any browser).
Install as app (PWA): host the folder on https or localhost, then use the "Install App" button in the menu.
  Local:  python -m http.server 8000   ->  open http://localhost:8000
  Online: drag this folder to Netlify Drop / GitHub Pages / Vercel.
  iPhone: Safari -> Share -> Add to Home Screen.
Controls: drag back like a slingshot, release to shoot. Headshot = 2.2x damage.
